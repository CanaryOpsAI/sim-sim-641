# CMP-1461 — Vision assessment evaluation harness and golden photo set

Build the harness the assessment job is measured against before it
ships: two hundred labelled contractor photos across the four pilot
trades, a scorer for structured-output accuracy per field, and a CI
job that runs the current prompt version against the set and fails
the build when accuracy drops more than two points from the recorded
baseline. Nothing customer-facing; without it STORY-005 and
STORY-006 cannot be tuned safely.

Acceptance (execution-specific):
- Golden set stored with labels; access restricted to the team.
- CI job green on the current prompt, red on a deliberately degraded
  one.
