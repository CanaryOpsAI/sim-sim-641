# CMP-1459 — Spike: evaluate address autocomplete providers for coverage and cost

Time-boxed to two days. Compare Google Places, Mapbox and the postal
service API on suggestion quality for rural addresses in the pilot
regions, per-request cost at the projected intake volume, and terms
that allow caching. Output is a one-page recommendation and the
proxy's provider adapter interface, so STORY-001's autocomplete step
can switch providers without a client change.

Acceptance (execution-specific):
- Recommendation reviewed with Platform; provider chosen and recorded
  in the ADR.
- Adapter interface merged with a stub provider behind it.
