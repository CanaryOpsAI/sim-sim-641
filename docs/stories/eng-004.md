# CMP-1462 — Spike: pricing model across the pilot trades -- rate-card schema, modifier order, rounding and tax

Before the estimate engine is built, settle how a rate is expressed
per trade (hourly, per unit or flat), the order modifiers stack in,
how tax applies per pilot region and how totals round to the
contractor's preference. Output is the versioned rate-card JSON
schema and twenty worked estimates agreed with two pilot contractors,
which STORY-007's engine tests must reproduce to the cent and
STORY-008's review screen displays as the contractor expects.

Acceptance (execution-specific):
- Schema reviewed with the pilot contractors and versioned in the
  repository.
- Twenty golden estimates checked in with both contractors' sign-off
  recorded.
